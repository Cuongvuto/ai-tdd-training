## Trọng tâm và evidence

Áp dụng quy trình 7 bước, phân loại Class of Service, cập nhật ticket trên Odoo
và soạn phản hồi phù hợp. Đây là phần thực hành nghiệp vụ, không phải module
code mới trong CLI.

Thư mục này hiện chứa tài liệu mentor và scenario; chưa có thư mục evidence
bàn giao W4 trong Git. Không suy ra đã hoàn thành thực hành chỉ từ việc các
file scenario tồn tại. Kết quả trên Odoo cần được kiểm tra riêng với mentor.

Tiếp nối: [Week 5](../week-5/README.md) sử dụng báo cáo ticket và bài toán
Login Issue để phân tích, xây dựng automation.
