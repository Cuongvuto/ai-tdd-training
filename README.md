# AI Training – TDD Research

## Overview

This repository contains the Week 1 research assignment on effective AI
collaboration, critical thinking, and Test-Driven Development for reliable CLI
tools.

The purpose of this assignment is to practice controlled AI usage while
researching testing principles and preparing for the implementation work in
the following weeks.

## Week 1 Topic

**Test-Driven Development for building reliable CLI tools with AI assistance**

## Learning Objectives

- Understand AI as a collaborative tool while the developer remains responsible
  for architecture, validation, and technical decisions.
- Understand Test-Driven Development.
- Explain the Red–Green–Refactor cycle.
- Distinguish unit, integration, and end-to-end testing.
- Identify appropriate tests for a Ticket Manager CLI.
- Use tests to validate AI-generated code.
- Recognize common testing mistakes and weak AI suggestions.
- Apply all three required AI workflows.

## Required AI Workflows

1. Layered Questioning
   - Research
   - Brief
   - Example
   - Validation

2. Solution Exploration
   - Explore alternatives
   - Compare advantages and disadvantages
   - Choose based on context

3. Iterative Refinement
   - Review
   - Summarize
   - Refine
   - Gather feedback
   - Validate
